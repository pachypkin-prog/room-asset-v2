# UI

1. **Каталог** — таблицы аудиторий и оборудования.
2. **Бронирования** — поиск, фильтры, список записей, редактирование и удаление.
3. **Форма бронирования** — ресурс, название, начало, окончание и примечания.
4. **Импорт/экспорт** — загрузка JSON и скачивание текущего набора данных.

Время в форме вводится в локальном часовом поясе браузера; перед отправкой преобразуется в UTC.
