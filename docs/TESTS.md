# TESTS

## Автоматические
Backend содержит unit-тесты для проверки пересечений бронирований.

Запуск: `npm --prefix backend test`.

## Ручные сценарии
1. Открыть каталог и убедиться, что отображаются аудитории и оборудование.
2. Создать бронирование свободного ресурса.
3. Создать второе бронирование того же ресурса с пересекающимся временем — сервер должен вернуть 409, UI показать ошибку.
4. Создать бронирование другого ресурса на то же время — операция должна пройти.
5. Изменить существующее бронирование.
6. Удалить бронирование.
7. Выполнить поиск по названию и примечаниям.
8. Отфильтровать список по дате и ресурсу.
9. Экспортировать JSON, изменить данные и импортировать файл обратно.
10. Проверить, что UTC-значения отображаются в локальном часовом поясе.
