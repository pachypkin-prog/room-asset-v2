# SPEC

## Назначение
Веб-приложение для каталога аудиторий и оборудования и управления бронированиями.

## MVP
- просмотр аудиторий и оборудования;
- создание, редактирование и удаление бронирований;
- запрет пересечений для одного ресурса;
- поиск по названию и примечаниям;
- фильтрация по дате и ресурсу;
- импорт и экспорт всех данных одним JSON-файлом;
- хранение времени в UTC в ISO-8601/RFC3339 и отображение в локальном времени пользователя.

## API
Backend предоставляет REST API `/api/rooms`, `/api/assets`, `/api/bookings` и `/api/data`.
