# DECISIONS

## Frontend/backend
Проект разделён на два независимых приложения: React/Vite frontend и Node.js/Express backend. Это соответствует архитектуре эталонного решения: frontend работает на 5173, backend предоставляет REST API на 4000.

## Хранилище
Для учебного проекта используется JSON-файл на backend. Это не требует отдельного сервера БД и сохраняет воспроизводимость запуска на Windows/Linux. Storage вынесен в отдельный модуль, поэтому его можно заменить на БД без изменения API.

## IndexedDB
Исходный монолит использовал IndexedDB. После разделения клиент-сервер IndexedDB удаляется из основного пути выполнения: данные принадлежат backend. Это предотвращает рассинхронизацию между клиентами.

## Проверка пересечений
Правило пересечений реализовано на backend и возвращает HTTP 409. Frontend отображает полученное сообщение.

## MSW
MSW можно подключить для изолированной frontend-разработки, но основной режим проекта использует реальный backend.
