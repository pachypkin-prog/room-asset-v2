# COMPAT

## Требования
- Node.js 20+;
- npm 10+;
- современный браузер с поддержкой ES2022.

## Windows/Linux
Backend использует `path`, `fs/promises` и URL-модуль Node.js без Unix-специфичных shell-команд. Для запуска можно использовать отдельные `npm` команды, одинаковые на Windows и Linux.

## Порты
- frontend: `5173`;
- backend: `4000`.
